# Product Glossary

Shared vocabulary for the launchpad product so specs, UI copy, and code agree.

- **Workspace** — the top-level container a user owns.
- **Project** — a unit of work inside a workspace.
- **Invitation** — a request for a person to join a workspace, with a role attached.
- **Onboarding** — the guided first-run flow after signup.
- **Backlog item** — a tracked unit of work; `backlog.md` is the visible list.

Rules:

- One concept, one name. Avoid synonyms in UI copy.
- New terms land here before they reach the interface.
